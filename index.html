NEXARIUM VERIFY MAIL

Nexarium
Verify Mail

01 / Executive
Summary

Executive Summary

Nexarium Verify Mail is a client-side email authentication solution that cryptographically links a defined representation of an email's content to a digital signature generated by an Ethereum-compatible wallet.

The purpose of the system is to associate verifiable data with an email so that it can later be determined whether a valid digital signature belongs to a specific email data set, and which Ethereum address the signature can be associated with.

02 / Operation

How does it work?

The system creates a standardized signData representation from defined email fields — sender, recipient, copies, subject, and message content. It hashes this using the SHA-256 algorithm and then has it digitally signed through the connected wallet's `personal_sign` mechanism.

The result is a structured ETH-VERIFY verification block containing, among other things, the hash value, the signature, and the wallet address. An independent verifier can recalculate the hash and verify the signature based on these data.

The model is:
Email data set → SHA-256 → wallet signature → independent verification
03 / Current
Technology

What does the current technology provide?

The current prototype makes it possible to cryptographically verify whether a valid wallet signature belongs to a specific email data set represented in a defined format, and which Ethereum address the signature can be traced back to.

This provides a layer of email authentication that is not based solely on a visual or textual claim, but on reproducible cryptographic data.

04 / Architectural
Boundary

What does the system not claim?

The current version deliberately does not automatically identify the following as being the same:

  • the owner of the email address and the owner of the wallet;
  • the wallet and the DID identity;
  • the digital signature and the legal identity.

The system also does not independently prove email delivery at present, nor does it record the email in an Ethereum transaction or on the blockchain.

This is an important architectural boundary: Nexarium Verify Mail is currently a cryptographic email authentication layer, not a complete identity or delivery system.

05 / Significance

Business and technological significance

The solution is based on a verifiable model in which email content, its cryptographic digest, and the wallet signature can be linked to one another. This provides a foundation for the development of an openly verifiable email authentication infrastructure.

With further development of the current architecture, the protocol could be extended to integrate identity data, DIDs, wallet addresses, timestamps, and document identifiers into a unified, cryptographically signed payload. Another optional direction is blockchain-based notarization of the hash of the signed data.

06 / Technology
Foundation

Current technology foundation

The reference implementation operates in a client-side JavaScript environment and is based, among other things, on the following technologies:

SHA-256 · Ethereum-compatible wallet · `personal_sign` · signature verification · DID-based identity metadata · ETH-VERIFY format · mailto-based email handoff
07 / Summary

Summary

Nexarium Verify Mail provides a technological foundation that links email data to a reproducible cryptographic representation and an Ethereum wallet signature.

The most important result of the current version is an independently verifiable cryptographic email-signing model. The next level of development could be a closer, formally defined integration of identity, signature, temporal information, and optional blockchain notarization.
